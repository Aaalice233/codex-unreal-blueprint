# 产品范围

v1 支持本机 Codex、UE4.27 Editor 和 Win64 Blueprint 自动化。支持 Blueprint 资产、继承、接口、Component、变量、函数、宏、Event Graph、UMG、AnimBlueprint、Struct、Enum 和 Blueprint Library。

v1 不支持 UE5、Material、Niagara、Sequencer、关卡 Actor 自动化、Runtime、远程 MCP、ChatGPT Web、独立 GUI、Unreal Dock 面板或自动源控恢复。UE 端只显示状态栏图标和 Tooltip；工作流由 Skill 与 MCP tools 承担。
