# Product scope

v1 supports local Codex, UE4.27 Editor, Win64, and Blueprint automation across assets, inheritance, interfaces, components, variables, functions, macros, event graphs, UMG, AnimBlueprints, structs, enums, and Blueprint libraries.

v1 excludes UE5, Materials, Niagara, Sequencer, level Actor automation, runtime use, remote MCP, ChatGPT Web, standalone GUI, Unreal dock panels, and automatic source-control recovery. UE exposes only a status-bar icon and tooltip; the Skill and MCP tools own the workflow.
